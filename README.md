# nodeshift-music-apps

приложухи для NodeShift Music — ios, андроид и винда. всё локально: треки, обложки, тексты лежат у тебя на телефоне/компе, сервер нужен только для входа через sso и для «слушать вместе».

дизайн 1в1 как у music.nodeshift.space, шрифты и иконка оттуда же.

## что тут лежит

- `ios/` — нативка на swiftui, без expo. собирается в github actions
- `shared/` — шрифты, иконка и тестовые данные, которые гоняют все платформы
- `site/` — страницы скачивания и манифесты обновлений для music.nodeshift.space/app
- андроид и винда — потом

## ios

собирается без подписи. ipa берёшь на music.nodeshift.space/app или из релиза `ios-latest`. ставить через sideloadly или altstore. бесплатный apple id = подпись на 7 дней, потом надо переподписать, поэтому лучше altstore/sidestore.

минимум ios 17.

## тесты

логика (парсер имён, тексты, дубликаты) лежит в `ios/Packages/NSMCore` и гоняется через `swift test`. тестовые данные в `shared/testdata` общие, андроид и винда потом будут проверяться теми же файлами.
